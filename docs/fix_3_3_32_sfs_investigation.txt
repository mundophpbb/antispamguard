AntiSpam Guard 3.3.32 - SFS investigation filters and review counters

Implemented:
- Added an SFS investigation search field for IP, email and username.
- Applied the search filter in both SFS log views.
- Preserved the search filter during pagination.
- Applied the same search filter to SFS CSV export.
- Added ACP counters for SFS review statuses: pending, reported, blocked, reported + blocked, allowed and total.
- Added migration v_3_3_32 with an investigation index for user_ip combined with created_at.

Notes:
- Search is substring-based for administrator convenience.
- Exact IP/email/username searches can benefit from the new indexes, while leading-wildcard substring searches may still require scanning depending on the database engine.
- This release is a UX/investigation refinement on top of the 3.3.29-3.3.31 SFS moderation work.
